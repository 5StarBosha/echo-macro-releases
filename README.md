# Echo Macro — Downloads

Automated Minecraft farming macro for Windows 10/11.

## Download

**[Latest release →](https://github.com/5StarBosha/echo-macro-releases/releases/latest)**

Download `EchoMacro-x.x.x.exe` from the latest release and run it. No installation required.

## Updates

Echo Macro checks for updates automatically. When a new version is available, you'll see a notification in the config editor.
